# 🥦 eatGrow — Nutrition You Can Afford, Near You
url-https://claude.ai/public/artifacts/69ea1ff2-828b-44ba-9055-e858f483a9d9

**eatGrow** is a lightweight, responsive web application designed to help individuals and families locate affordable, nutrient-rich fruits and vegetables in their immediate vicinity. The platform bridges the gap between budget constraints and nutritional needs by offering dynamic filtering across location, cost, protein content, and caloric values.

## ✨ Features

- 📍 **Location-Based Discovery**: Filter fresh produce by major metropolitan cities (*Mumbai*, *Delhi*, *Bengaluru*) and local neighborhood areas.
- 🥗 **Nutritional & Budget Filtering**:
  - Filter by **Price Range (₹/kg)**.
  - Set a minimum threshold for **Protein content** (g / 100g).
  - Set maximum cap for **Calories** (kcal / 100g).
  - Categorize by **Fruits** or **Vegetables**.
- 🏪 **Store Locator & Price Comparison**: View nearby grocery stores/mandi vendors with real-time dynamic pricing based on location factors and instant **Google Maps Directions**.
- 🔄 **Smart Alternatives**: Discover alternative produce options with comparable nutritional profiles and price points.
- 📱 **Fully Responsive UI**: Modern design styled with custom typography (*Fraunces*, *Inter*, *IBM Plex Mono*), card layouts, animated bars, and mobile-friendly collapsible filters.
- 👤 **Personalized Session**: Optional user login modal with personalized header greetings.
